# 🧮 Calculadora Interativa em C

Uma aplicação simples em linha de comando desenvolvida em linguagem C que realiza operações matemáticas básicas entre dois números com base na escolha do usuário.

## 🚀 Funcionalidades

O programa permite ao usuário inserir dois números reais e escolher uma das seguintes operações:
- ➕ **Soma** (Opção 1)
- ➖ **Subtração** (Opção 2)
- ✖️ **Multiplicação** (Opção 3)
- ➗ **Divisão** (Opção 4)

Ao final, exibe o resultado da operação na tela.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C
- **Biblioteca Padrão:** `stdio.h` (para entrada e saída de dados)

## 💻 Como Rodar o Projeto

Para compilar e executar este programa na sua máquina, você precisará de um compilador de C (como o `gcc`).

### Passo 1: Clonar o repositório
```bash
git clone https://github.com
cd NOME-DO-REPOSITORIO
```

### Passo 2: Compilar o código
No terminal, execute o comando abaixo para compilar o arquivo (substitua `calculadora.c` pelo nome do seu arquivo de código):
```bash
gcc calculadora.c -o calculadora
```

### Passo 3: Executar o programa
No terminal, rode o arquivo gerado:

- **No Windows:**
  ```cmd
  calculadora.exe
  ```
- **No Linux/macOS:**
  ```bash
  ./calculadora
  ```

## 📝 Exemplo de Uso
```text
primeiro número: 10
```
